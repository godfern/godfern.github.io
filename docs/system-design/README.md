# Frontend System Design — Interview Preparation

System design rounds for frontend engineers test your ability to architect scalable, performant, and maintainable UIs. Unlike backend system design, the focus shifts from servers and databases to component architecture, state management, rendering strategies, and the browser.

## What interviewers are looking for

- Can you **drive the conversation** and ask clarifying questions before diving in?
- Do you make **explicit trade-offs** rather than picking one solution blindly?
- Can you think about **scale** — millions of users, dozens of teams, multiple platforms?
- Do you consider **non-functional requirements** — performance, a11y, security, offline support?
